---
title: Video canvas plugin
description: Canvas to render a video into a `<video>` element
---

It is used to play streams containing videos that can be displayed using a `<video>` tag.


## Configuration

**config.json:**

```json
{
    "plugins" : {
        ...
        "es.upv.paella.videoCanvas": {
            "enabled": true,
            "order": 1
        }
    }
}
```
